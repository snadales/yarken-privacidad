# Política de seguridad

Repos privados de uso personal y del negocio del dueño (`snadales`). No hay versiones soportadas ni programa de reportes públicos.

- Si encuentras una vulnerabilidad o un secreto expuesto, avisa al dueño directamente (no abras un issue con el valor).
- Los secretos nunca van en archivos: solo referencias `op://IA/<item>/<campo>` (1Password).
- Un secreto filtrado se considera comprometido: se rota primero y después se limpia el historial.
